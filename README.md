
# 🎈 Bubble Game using JavaScript

This is a simple and fun **Bubble Game** built using **HTML, CSS, and JavaScript**. The player has to click on the correct bubble number within a given time to earn points.

## 🕹️ How to Play

- A random number is shown at the top.
- Click the bubbles with the matching number to score points.
- You have a limited amount of time to score as much as possible.

## 🛠️ Tech Stack

- **HTML** – Structure of the game.
- **CSS** – Styling and animations.
- **JavaScript** – Game logic, timer, score handling, and interactions.


## 📁 Folder Structure

```
Bubble-Game-using-JS/

```

1. Clone the repository:
   ```bash
   git clone https://github.com/aftabmadni/Bubble-Game-using-JS.git
   ```
